# Full check — 2026-11-14

His ask: "give all versions of shlimpnote a detailed check on functionality and features".
Checked: computer size (1280×860), phone size (390/500 wide), the PIN lock, phone↔computer
sync merging, the live site, and opening with no internet. All on `?demo` data or a
throwaway browser profile — her real data was only read (to see goals), never changed.

## How it was tested
A Firefox remote-control script clicked through every page and feature and read the saved
data back after each step (no script errors in the browser log on any run):
- Today: tick a dose, a chore, a goal; card links.
- Meds: add (name, dose, times), tick dose, 7-day strip, edit in place, remove + Undo.
- Cycle: day light → medium → heavy → clear, prediction cards, dashed expected days, month arrows.
- Notes: new note autosaves, search, pin, delete + Undo.
- Chores/Work: Enter adds, Shift+Enter doesn't, repeat chip, Done fold, edit in place, Esc
  cancels, drag by the grip with a finger.
- Goals: add, steps, tick step, tick goal (sinks below open goals), remove + Undo.
- Journal: feelings grid → writing, change feeling / Keep, old days keep their emoji.
- Ask for a change: request shows as Waiting. Your devices page draws.
- Everything still there after a reload. Sidebar navigation.
- PIN: make, mismatch, wrong PIN, keyboard and keypad, locks again after 5 min away,
  Change PIN, Cancel, "Forgot it?" without a code.
- Sync merge: 11 cases (both devices change different things, edit vs delete both ways,
  PIN changed on one/both devices, period day cleared, all goals removed, first sync).
- Live site: every file in `sw.js` loads (200). Offline: service worker serves the saved copy.

## Found and fixed
1. **Typing got wiped**: 6 s after removing something, the fading "Undo" line redrew the
   page and erased whatever she was typing. Now the line just fades away.
2. **Phone: hidden buttons**. A row's × and "Once / Every day" chip (and the drag grip) only
   showed on mouse hover, which phones don't have. Now always shown on touch screens; the
   chores hint no longer says "hover".
3. **Phone: dragging rows didn't work with a finger**. Holding the ⠿ grip and sliding now
   reorders on touch screens too.
4. **Sync: an edit could be lost**. If one device deleted something while the other edited
   it, the edit was dropped on one side. Now the edit wins both ways (as intended).
5. **Requests could be sent twice** if a sync landed while one was being sent. Sending now
   runs one at a time and writes onto the current data.
6. PIN keypad handler no longer throws on key events that don't come from an element.
